# SignalFlow Mini V1 RD2 Agent Boundary

This public candidate is a bounded rebrand/productization of the owner-supplied ReoFlow V1 RD2 speech-to-text module.

Protected behavior: local recognizer/model path, capture format, pre/post roll, transcription flow, clipboard recovery, paste target/focus guards, installer rollback, dependency pins, global F8 behavior, and the non-activating listening/transcribing overlay.

Do not expand SignalFlow Mini into the larger Signal Flow studio in this repository. Future Signal Flow work belongs to its separate governed build workstream.
